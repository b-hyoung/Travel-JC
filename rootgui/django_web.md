#### 회원가입
- 이름 (여권 영문명)
    - 여권에 기재된 로마자(영문) 이름으로 통일해서 받을 것 (모국어 입력 불가) 
- 비밀번호 
    - 1~10자 이내 x -> 최소 10자 이상
- 계정 정책
    - '비자 만료일' 필드 삭제.
    - 가입일 기준 120일 뒤 계정 자동 삭제 정책으로 통일.
#### 실제 페이지
    - 언어 변경을 해도 실제 페이지에는 한국어만 나옴
#### 언어 처리
    - 마지막 선택한 언어 정보 저장해뒀다가 이후 로그인 했을떄 참고 하여 언어 로드해주기
    ex) 이전에 eng를 선택했다면 해당 정보를 localstorage에 저장 후 이후 로그인 / 로드 시 언어정보 자동으로 불러오기
    - qr을 타고들어오는 웹정보에 https://web.com?lang=ko / lang=eng / lang=jp 등등 확인해서 있으면 언어정보로 먼저 로드해주기

#### 사전 안내 방식
 - **회원가입 페이지:** "소중한 개인정보 보호를 위해, 가입 계정은 120일간 유효하며 이후 안전하게 자동 삭제됩니다." 문구 명시.
 - **사용자 대시보드:** "개인정보 보호를 위해, 회원님의 계정은 삭제 예정일(YYYY-MM-DD)에 모든 정보와 함께 자동 삭제될 예정입니다." 안내.
